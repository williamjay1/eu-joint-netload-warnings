## Files and reading order

- [Supplemental_Materials_bundle.zip](Supplemental_Materials_bundle.zip): one download containing the supplemental PDF, Fig. S1, all 36 CSV files, the ten complete supporting-table Markdown renderings, indices and licensing/attribution notes. This convenience archive excludes itself and `manifest_sha256.json` to prevent a checksum cycle; the external manifest covers the archive and every hosted content file.
- [Supplemental_Materials.pdf](Supplemental_Materials.pdf): the supplemental document, Sections S1–S15, including the technical specifications, complete comparisons, sensitivity analyses and Fig. S1.
- [Fig_S1.pdf](Fig_S1.pdf): Fig. S1, post hoc priority-rule examples, also included in Section S15 of the supplemental document.
- [table_exports/index.md](table_exports/index.md): a reader-facing mapping of the 26 unchanged CSV exports to their actual supplementary labels or section headings.
- [table_exports/original_index.md](table_exports/original_index.md): the original export index retained verbatim for provenance. Its historical source-file name identifies the earlier export source, not a journal submission destination.
- [supporting_tables/index.md](supporting_tables/index.md): ten additional complete supporting tables cited by file name in Sections S9–S13. Each is provided as unchanged CSV and Markdown, with the original source index and manifest retained.
- [manifest_sha256.json](manifest_sha256.json): file sizes and SHA-256 checksums for the hosted document, figure, indices and CSV exports. The manifest does not hash itself.
- [LICENSE_AND_ATTRIBUTION.md](LICENSE_AND_ATTRIBUTION.md): standalone licensing and source-attribution notes, also included in the convenience archive.

Directory-specific Git attributes preserve the supplied bytes and line endings, so checksums identify the published files as well as the local copies.

The number in `supplementary_table_01.csv` through `supplementary_table_26.csv` is an export sequence. It is **not** the scientific table label. In particular, these files must not be cited as “Tables S1–S26.” Reading-guide, glossary and multiplicity-family exports retain their section headings; named scientific tables retain labels such as Table S9.1 or Table S10.6a. The separate `supporting_table_01.csv` through `supporting_table_10.csv` files complete the larger tables explicitly referenced in the supplemental document. The two file-numbering sequences refer to separate sets and are not interchangeable.

## Interpretation and reuse

The methods and reported numerical results remain those in the submitted study. The electricity observations are revised source archives evaluated through delayed replay; the materials do not recover all historical publication vintages or validate live operational availability. Fig. S1 contains post hoc illustrations rather than an additional independent validation sample. The simulated experiments are explicitly identified in the document.

The author-written supplemental document, Fig. S1 and author-produced table exports are available under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Author-written software elsewhere in the repository is under MIT. Source attribution and retained third-party rights are detailed in [LICENSE_AND_ATTRIBUTION.md](LICENSE_AND_ATTRIBUTION.md), [DATA_LICENSES.md](../DATA_LICENSES.md) and [DATA_SOURCES.md](../DATA_SOURCES.md). No raw provider archives, raw MW/weather-grid/price time series, fitted model objects or credentials are added here.
