# Scope and prerequisites of a new model fit

The tested command `python reproduce.py` evaluates the released, already-issued probabilities. It does not acquire provider observations, extract GEFS fields, fit margins or re-select models. This distinction matters: numerical evaluation can be reproduced from the released derivatives, while a fresh raw-data fit requires the source archives and recorded preprocessing contracts.

The broader source in `scripts/` is supplied to inspect or rebuild the scientific pipeline. It is not advertised as a one-command raw-data reproduction. Acquisition APIs and revised observations can change; an independently obtained contemporary snapshot may differ from the study input hashes. The study did not recover all historical publication vintages. Do not describe a new download as the exact historical information set.

The dependency record is `requirements-pipeline.txt`; GRIB decoding can require native ecCodes. The pipeline proceeds through:

1. Acquisition of SMARD, RTE éCO2mix and Elia public observations (`data_download_observations.py`), immutable provider snapshots and source receipts. Danish settlement acquisition and accounting are in `upgrade_data_audit_20261002.py`.
2. UTC interval-start normalisation and provider-native hourly MW construction (`data_normalize_observations.py`, `data_build_native_v3.py`). Regional accounting remains provider specific.
3. Archived GEFS range acquisition, common regional field extraction and weather-feature panels (`gefs_download.py`, `gefs_regional_features.py`, `weather_panel_builder.py`). Natural Earth boundaries are an approximate mask, not capacity weighting.
4. Seasonal threshold history and rolling raw margins/beta recalibration (`adaptive_thresholds.py`, `prequential_margins.py`, `margins.py`), with chronological delayed-label eligibility.
5. Issued joint forecasts (`joint_forward_runner.py`, `dependence.py`, `joint_pair_products.py`) and the fixed additional conditional-map/shared-correlation factorial (`upgrade_margin_dependence_20261002.py`).
6. Local Danish refits/transfers (`upgrade_external_transfer_20261002.py`) and forecast-only review allocation (`upgrade_warning_policies_20261002.py`, `upgrade_external_warning_policies_20261002.py`).

The original scripts use hash-checked preprocessing/model provenance and guarded output directories. Recorded frozen settings identify the study inputs; they do not supply missing private cache files or relax provenance gates. Before a fresh fit, rebuild each required dataset/feature/timing/availability contract, review the command arguments and configure work/raw roots. A path adaptation can change code hashes; record the adaptation and its equivalence, rather than falsely reusing a historical source hash. Files under `config/` document scientific settings; missing production manifests and large intermediates must be rebuilt at their corresponding stage.

The release's optional acquisition/modelling source resolves its work root from the clone unless `EU_NETLOAD_WORK_ROOT` is set. The raw root is explicitly configurable with `EU_NETLOAD_RAW_ROOT`; its Windows default is `F:/AcademicData/eu_joint_netload/raw`, and its default on other systems is `<work>/raw`. Create and inspect the intended immutable raw directory before acquisition. On the author's Windows machine, computation must be on D: and new raw downloads on F:, so keep the clone/work root on D: and check F: space before any download. An unavailable configured drive is not a reason to write training or raw downloads to C:. Preserve old raw snapshots and create a new dated snapshot. No raw acquisition command is executed by the repository's verification command. On other systems, choose explicit work/raw directories and retain the same safeguards against overwriting raw material. Drive-letter-only guards were adapted to equivalent configured-subtree guards; raw-overwrite and output-version protections are retained. The recorded source-adaptation document names these changes.

The optional `astral` dependency is used by a solar extraction pathway; it was not installed in the recorded tested evaluation environment and is listed as an optional pipeline requirement, without a fabricated installed version. The statistical reconstruction and delivered plotting commands do not import or require it.

The exact portable reconstruction validated here is: hourly issued probability/event/plan tables → complete-day scores and intact event processes → native and matched review outcomes → daily paired contributions → post hoc block-bootstrap intervals and Holm checks. The current figure/table renderers use only compact released derivatives and table cells. Full raw refitting, live shadow monitoring and operator behaviour are not claimed as newly validated by the release.
