# Manuscript sources

These Markdown sources and the BibTeX database are the inputs of `scripts/build_documents.py`. They are
included so that the exact article and supporting information text used for the reported results can be
regenerated and checked. They are documentation of the document build, not part of the analysis code.

The journal submission formats (Word and PDF) are not redistributed here; the analysis itself is
reproduced from `scripts/`, `datasets/` and `results/`.
