# ASMBI substantive revision — analysis protocol (8 October 2026)

This is a new, post hoc analysis of previously inspected 2024–2025 forecasts. It is not a preregistration or a fresh holdout. Existing ASCE files and archived raw materials remain unchanged.

Primary question: How do a daily review cap, process-level benefit, and marginal forecast perturbations change the value of selective review? The scientific contribution is an empirically auditable connection between forecast scores and actual selections, including failure boundaries. No new copula or optimal-control theorem is claimed.

## Population and information
Three original bidding zones (DE-LU, FR, BE); Denmark replacements DK1 and DK2 are transfer settings sharing DE-LU and FR, not independent replications. Delivery hours are UTC. Allocation sees only complete forecast days; incomplete future outcomes affect scoring afterward. Archived output records issue D−1 12 UTC; provider data and assumed maturation lags describe a delayed replay, not recoverable historical data vintages. Existing labels and physical thresholds remain fixed.

## Analysis contracts fixed before the new computations
* Model streams: M0 baseline recalibrated margins/Gaussian, M1 mapped margins/Gaussian, M2 baseline recalibrated margins/selected t, M3 mapped margins/selected t. All share the correlation matrix and data splits.
* Primary endpoint: first six-hour coverage of event-day processes, bridge one fully observed inactive day; onset is first actual event hour, interval [onset,onset+6h), evaluated only after allocations. Gap zero/two and q95 are sensitivity analyses.
* Daily cap K=2; a slot is a selected delivery-hour window, not a measured staff-hour. Include no-review, Top1, Top2, static gate .25, original risk-rise/cooldown .19, and a rolling forecast-only gate targeting .5 slots/day using preceding 90 issued forecast days. Do not tune using evaluation outcomes or force an exact annual realized quota.
* Isolate rank and cooldown at common threshold .25. Four model streams use both a common gate and model-specific gates chosen from 2022 forecast counts; 2023 validates development behavior. Historical policy selection is retained as historical selection, not newly prospective selection.
* Utility scenarios: separately process utility C−rN and event-hour utility H−rN. Include no-review and a complete cost range. No empirical wage/dispatch cost interpretation. Original uniform retention is an exact expected exposure-standardization benchmark, not an executable annual-budget controller.
* Decompose first early detections, subsequent early detections of the same process, late event detections, and selected non-events. Examine all three processes missed by the static gate relative to Top2.
* Uncertainty: synchronized 14-calendar-day moving blocks within year/quarter, holding fitted forecasts, rules, and process boundaries fixed. Preserve intact contributions by process onset; do not refit or reconnect episodes. Report what this conditional uncertainty omits.
* Perturbations: declared fixed-copula local CDF shifts of .01/.03, not estimated as development-error bounds, explicitly a sensitivity set, not hourly confidence intervals. Evaluate gate crossings, top-two ranks and complete cooldown replay. Verify numerical integration against stricter convergence and independent randomized CDF computations before interpreting small score differences.
* Early-window model: simple regularized logistic classifier, features available at issue only, target event in first six hours. Use 2022 for fitting and 2023 for penalty validation and the primary common resource-count contract; quarterly refits require hour_end plus seven days (original) or fifteen days (Denmark) before issue. Retain temporal order. No actual target-day net load or realized preceding events as predictors. Denmark price comparisons use explicitly assumed day-ahead-price availability when historical publication vintages cannot be reconstructed.
* Mechanistic simulations follow ADEMP: true probabilities and temporal processes, marginal perturbation location, dependence, persistence, distribution shift, and onset signal. Report replication counts and Monte Carlo standard errors; synthetic evidence is clearly separate from observed data.

## Publication
Target ASMBI Research Article, editable initial manuscript; main text <=250-word abstract and <=5 keywords. Supporting information is submitted separately with the manuscript and named Appendix/Figure/Table S*. Wiley AI disclosure reflects actual analysis, drafting and coding assistance. Existing Zenodo DOI supports the earlier release; it must not be described as containing these unpublished new analyses. Final output includes reproducible scripts, derivative evaluation data and a requirements closure matrix. No external submission, withdrawal or repository release is performed by this task.
